MONEY PLAN - installable offline app

1) Put this whole folder online (any static host, HTTPS required):
   - Netlify: go to app.netlify.com/drop and drag this folder onto the page.
   - GitHub Pages: upload the files to a new repo, then Settings > Pages > deploy from main branch.
2) Open the link on your phone.
   - Android (Chrome): menu (three dots) > Install app / Add to Home screen.
   - iPhone (Safari): Share button > Add to Home Screen.
3) After the first load it works offline.

Your data is stored on the device only. Use "Export backup (CSV)" regularly.
Imports restore from that same CSV file.
